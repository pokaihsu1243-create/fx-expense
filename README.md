# 出差報支匯率查詢

國外出差回來報支用：填入**消費日期、類別、外幣金額**，自動套用**兆豐銀行「歷史匯率」**當天的匯率，算出可報支的台幣，並產生一張可存成圖片／PDF 的報支表當佐證。

## 直接開網頁使用（同事看這裡）

👉 **<https://pokaihsu1243-create.github.io/fx-expense/>**

不用安裝任何東西，電腦、手機都能開。

1. 逐列填：消費日期、類別（餐費／計程車／交際費…可自己打）、說明、幣別、金額。
   - 出差好幾天可用「快速產生連續日期」一次產生多列；列可以拖曳 ⠿ 或按 ↑↓ 調整順序。
2. 按「**算台幣**」，下方產生報支表：
   - 「**存成圖片（佐證）**」→ 下載 PNG 到「下載」資料夾
   - 「列印／存 PDF」、「複製表格（貼到 Excel）」
   - 「開兆豐官網核對」→ 開兆豐歷史匯率頁，可自行截官網畫面

填過的資料**只存在自己電腦的瀏覽器裡**，不會上傳到任何地方；下次打開還在，按「清空」才會刪除。
換電腦或換瀏覽器時，用「匯出紀錄」存成檔案，再到新的地方「匯入紀錄」。

## 換算規則（依公司會計的報支算法）

| 項目 | 規則 |
|---|---|
| 銀行 | 兆豐國際商業銀行 |
| 匯率 | **即期・銀行買入** |
| 日期 | 消費當天；假日／休市沒有牌告，往前取最近一個營業日（表上會註明） |
| 時點 | 預設「營業日最後一次匯率（約 16:00）」，可在「算台幣」旁切換 |
| 台幣 | 每筆 外幣 × 匯率 四捨五入到元，各類別小計＝各筆加總 |
| 新台幣支出 | 幣別選 TWD，不換算直接列入 |

## 匯率資料怎麼來的

兆豐官網不允許其他網頁直接讀取，所以由 GitHub 每天自動到兆豐官網抓即期買入匯率，存在本儲存庫的 `data/` 資料夾，網頁再讀這些檔案換算。

- 每天台灣時間約 **16:40** 抓一次、**20:30** 補抓一次，**當天的匯率要下午 5 點後才查得到**。
- 網頁版只保留**最近 3 個月**的匯率，更早的會自動刪除。出差回來請在 3 個月內報支並存好佐證；超過 3 個月的可用下方本機版查（兆豐官網保留一年）。
- 兆豐只有提供即期匯率的幣別才查得到（美元、日圓、歐元、人民幣、港幣、英鎊、澳幣、加拿大幣、新加坡幣、瑞士法郎、泰銖、紐元、瑞典幣、南非幣）。韓元、越南盾等只有現金匯率的幣別，請直接用 TWD 填信用卡實際扣款的台幣金額。
- 若兆豐改版導致自動更新失敗，網頁會顯示「匯率還沒更新」，請通知維護人。
