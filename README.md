# 出差報支匯率查詢

國外出差回來報支用：填入**消費日期、類別、外幣金額**，自動到**兆豐銀行官網「歷史匯率」**抓當天匯率，算出可報支的台幣，並產生一張可存成圖片／PDF 的報支表當佐證。

## 下載與使用（同事看這裡）

1. 到右邊 **Releases** 下載最新版的 `FxExpense.exe`。
2. 雙擊執行。會跳出一個黑色視窗，瀏覽器自動打開查詢頁面。
   - **黑色視窗不要關**，關掉工具就停止；用完再關即可。
   - 第一次執行若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」（這是因為程式沒有數位簽章）。
3. 在頁面上逐列填：消費日期、類別（餐費／計程車／交際費…可自己打）、說明、幣別、金額。
4. 按「**算台幣**」，下方產生報支表：
   - 「**存成圖片（佐證）**」→ 下載 PNG 到「下載」資料夾
   - 「列印／存 PDF」、「複製表格（貼到 Excel）」
   - 「開兆豐官網核對」→ 開兆豐歷史匯率頁，可自行截官網畫面

填過的資料會留在自己電腦的瀏覽器裡，下次打開還在；按「清空」才會刪除。

## 換算規則（依公司會計的報支算法）

| 項目 | 規則 |
|---|---|
| 銀行 | 兆豐國際商業銀行 |
| 匯率 | **即期・銀行買入** |
| 日期 | 消費當天；假日／休市沒有牌告，往前取最近一個營業日（表上會註明） |
| 時點 | 預設「營業日最後一次匯率（約 16:00）」，可在「算台幣」旁切換 |
| 台幣 | 每筆 外幣 × 匯率 四捨五入到元，各類別小計＝各筆加總 |
| 新台幣支出 | 幣別選 TWD，不換算直接列入 |

## 注意

- **需要網路**（要連兆豐官網查匯率；存圖片功能也要網路）。
- 兆豐官網只保留**最近一年**的歷史匯率，超過一年的日期查不到，出差回來請盡早報支並存好佐證。
- 匯率來源是兆豐官網，若兆豐改版，工具可能要更新，請通知維護人。
- 佐證圖是本工具產生的換算表；會計若要求官網原始畫面，請用「開兆豐官網核對」自行截圖。

## 有裝 Python 的人

不用 exe 也可以：下載原始碼後執行 `python server.py`（只用 Python 標準函式庫，免安裝套件），瀏覽器開 <http://localhost:8728>。
